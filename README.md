# Innova Schools - Generador Automático de Sesiones PPTX

Aplicación web desarrollada para la docente **Araceli** (Innova Schools - Secundaria).

## 🎯 ¿Qué hace esta herramienta?
Permite transformar automáticamente un **Plan de Sesión pedagógico (`.docx`)** en una **Presentación de Clase completa (`.pptx`)** de 16 diapositivas, siguiendo estrictamente:
- La metodología Communicative Language Teaching (CLT).
- El sistema de diseño visual de Innova Schools (paleta `#00669E`, `#741753`, `#EA8118`, `#8CBA37`, `#C9DAF8`).
- Temporizadores visuales (2 min, 3 min, 7 min).
- Organizadores gráficos y rúbrica ministerial oficial (C, B, A, AD).
- Imágenes fotorrealistas contextualizadas según la unidad y tema.

## 🚀 Despliegue en Streamlit Cloud
Esta aplicación está lista para ejecutarse directamente en **Streamlit Community Cloud** con el archivo principal `app.py`.
